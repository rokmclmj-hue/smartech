# 케이스: 반도체·디스플레이 장비 — Loadlock/Buffer 챔버 배기

## 시스템 구성
- Loadlock 챔버(#1): 체적 3,600 L / 목표압력 5.0E-02 torr 이하 / Process·Cleaning Gas 없음 / 배관 구경 ISO200(자료상 이미지에는 ISO250로도 표기 — 출처 간 불일치 있어 확인 필요) / 배관 길이 10M / 엘보 4회
- Buffer 챔버(#2): 체적 52,600 L / 목표압력 5.0E-02 torr 이하 / 조건 동일

## 시뮬레이션 결과 (Edwards 공식 시뮬레이션, 2025-07-31)

**Loadlock 챔버(3,600L) — GXS450/4200 vs GXS750/4200 비교**
- GXS450/4200 x 2대: 목표압력(5×10⁻² torr) 도달 88초
- GXS750/4200 x 2대: 목표압력(5×10⁻² torr) 도달 63초

**Buffer 챔버(52,600L) — GXS750/4200 세트수별 비교**
- GXS750/4200 x 1 set: 도달 25분
- GXS750/4200 x 2 sets: 도달 13분
- GXS750/4200 x 3 sets: 도달 9분
