# 케이스: 반도체·디스플레이 장비 — Loadlock/Buffer 챔버 배기

## 시스템 구성
- Loadlock 챔버(소형, 수천 L급): 목표압력 10⁻² torr대 / 공정·세정 가스 없는 순수 배기 조건 / 중구경 배관, 짧은 배관 길이, 엘보 소수
- Buffer 챔버(대형, 수만 L급): 목표압력·배관 조건은 Loadlock과 동일, 체적만 약 15배 규모

## 시뮬레이션 결과 (Edwards 공식 시뮬레이션, 2025년 3분기)

**Loadlock 챔버 — 펌프 모델 비교**
- 산업용 드라이펌프(중형 클래스) x 2대 구성: 목표압력 도달 약 90초 내외
- 산업용 드라이펌프(대형 클래스) x 2대 구성: 목표압력 도달 약 1분 내외 — 대형 클래스가 더 빠름

**Buffer 챔버 — 펌프 세트 수별 비교**
- 1 set 구성: 도달 약 20분대
- 2 sets 구성: 도달 약 10분대
- 3 sets 구성: 도달 10분 미만 — 세트 수 증가에 따라 도달 시간이 비례 이상으로 단축

## 적용 산업
