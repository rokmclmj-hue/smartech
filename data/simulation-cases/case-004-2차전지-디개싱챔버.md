# 케이스: 2차전지 디개싱(Degassing) 챔버 — 소형 다연 배기 시스템

## 시스템 구성
- 펌프: EXS450 x 1 set
- 목표 진공도: -95 kPaG (= 63 mbarA), 도달시간 10초 이내 요구
- 배관 길이: 50M, 배관 사이즈 구성: Merge 전 25A→40A, Merge 후 25A→80A로 확장, 벤드 수 20EA→10EA로 축소
- 배기 대상: 120ml Hopper(호퍼) 통 60개 + 배관 체적 약 10L (챔버 유효 체적 7.2L 기준, 0.12L×60개)

## 시뮬레이션 결과 (Edwards 공식 시뮬레이션, 2025-12-16)
- 10 sets 구성: EXS450 Tact Time 6.7초 (ATM → 63 mbarA)
- 16 sets 구성: EXS450 Tact Time 9.7초 (ATM → 63 mbarA)

## 공정 특성상 주의사항 (Edwards 시뮬레이션 자료 자체 명시)
- 전해질(electrolyte) 물질의 증기압 특성에 따라 배기 시간·도달 진공도가 달라질 수 있음(시뮬레이션은 전해질 특성을 반영하지 않음)
- Degassing 챔버 투입 생산품 양과 노출 표면적에 따라 기화량이 달라짐
- On-off valve에 전해질 증기가 누적되면 밸브 응답 속도(response time)가 느려질 수 있음
- 배관(foreline) 내부에 증발된 전해질 물질이 누적되면 생산 횟수가 많아질수록 도달 진공도에 영향

## 적용 산업
2차전지(리튬이온배터리, LiB) 제조 공정 — 전해질 디개싱(탈기) 챔버, 다수 소형 챔버 동시 배기 시스템
