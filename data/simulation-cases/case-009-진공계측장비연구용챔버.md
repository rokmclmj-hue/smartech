# 케이스: 진공 계측기기 연구용 레퍼런스 챔버 — 터보+스크롤 조합 배기

## 시스템 구성
- 챔버: 소형 레퍼런스 챔버(연구·계측장비 교정용)
- 펌프 구성: 터보분자펌프(nEXT급) + 스크롤 드라이펌프(nXDS급, 소형/중형 2종 비교)
- 배관: 소구경 튜브(수mm급) + 표준 플랜지 조합
- Outgassing rate: 8×10⁻⁷ mbar·l/s·cm² (가정치)

## 시뮬레이션 결과 (Edwards 공식 시뮬레이션)
- 백킹펌프(스크롤) 용량을 소형→중형으로 올려도 최종 도달 진공도(초고진공 영역, ~10⁻⁶ torr대)에는 차이가 거의 없음
- 초기 배기 구간(수백 초 이내)에서는 중형 백킹펌프가 소형 대비 빠르게 저진공 구간을 통과
- **outgassing rate 가정치 민감도**: 같은 시스템이라도 outgassing rate 가정을 8×10⁻⁷ → 1.8×10⁻⁷ mbar·l/s·cm²로 낮추면(표면처리·재질 개선 등으로 실제 outgassing이 적은 경우) 최종 도달 진공도가 약 5×10⁻⁶ torr → 1.7×10⁻⁶ torr로 3배 가까이 개선됨 — 백킹펌프 용량보다 이 가정치 하나가 결과에 훨씬 크게 영향을 줌
- **핵심 인사이트**: 최종 도달 진공도는 백킹펌프(러핑펌프) 용량보다 배기 대상의 outgassing율, 포어라인 컨덕턴스, 진공게이지 설치 위치에 의해 더 크게 좌우됨 — 백킹펌프를 키운다고 최종 진공도가 비례해서 좋아지지 않음

## 적용 산업
진공 계측기기(게이지) 연구개발용 레퍼런스 챔버 — 터보분자펌프+스크롤펌프 조합 초고진공 시스템
