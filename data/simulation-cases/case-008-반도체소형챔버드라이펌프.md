# 케이스: 반도체 공정 소형 챔버 — 드라이펌프 배기속도 비교

## 시스템 구성
- 챔버: 소형(수십 L급)
- 포어라인: 짧은 배관, 중구경, 벤드 소수
- 목표압력: 1torr 미만 영역

## 시뮬레이션 결과 (Edwards 공식 시뮬레이션)
동일 챔버·배관 조건에서 산업용 드라이펌프 여러 모델의 목표압력 도달 시간을 비교한 결과, 배기속도 등급이 높은 모델일수록 도달 시간이 짧게 나타남(수 초 단위 차이). 소형 챔버에서는 펌프 배기속도 차이가 도달 시간에 비교적 크게 반영됨.

## 적용 산업
반도체 제조 공정 — 소형 프로세스/로드락 챔버 배기 시스템
