# 케이스: 디스플레이 포토(Photo) 라인 — PR 코팅 후 용제 증발(VCD) 공정

## 시스템 구성
- 공정: PR(포토레지스트) 코팅 직후 용제(solvent) 증발 건조 — VCD(Vacuum Contact Drying)
- 챔버: 250 L, 스테인리스강(Viton 씰)
- 목표 진공도: 50 Pa
- 배관: ISO100 구경, 챔버-밸브 1.7m(2벤드) + 밸브-펌프 2.4m(2벤드)
- 비교 펌프: EXS750(단독) vs EXS750/4200(콤비, 부스터 통합)

## 시뮬레이션 결과 (Edwards 공식 시뮬레이션)
- EXS750 단독: 대기압 → 50 Pa 도달 14.0초
- EXS750/4200 콤비(부스터 통합): 대기압 → 50 Pa 도달 8.8초 — 단독 대비 약 37% 단축

## 핵심 인사이트
PR 코팅 직후 용제 증발(VCD) 공정처럼 **택트타임이 생산성에 직결되는 단위공정**에서는, 콤비형(부스터 통합) 드라이펌프로 교체하는 것만으로 배기시간을 큰 폭(이 사례 기준 37%)으로 줄일 수 있음 — 별도 부스터를 추가하는 것보다 콤비 모델 자체를 선택하는 것이 설치 공간·배관 구성 측면에서도 유리.

## 적용 산업
디스플레이 포토 라인 — PR 코팅 후 용제 증발 건조(VCD) 공정, 택트타임 단축을 위한 펌프 선정
