## Astra 운영으로 이어갈 때 보완할 규칙

1. **좋은 검수는 유지:** 기술 수치·제품 분류·기능·공식 조합 검증, 실제 상담만 활용, 고객 정보 익명화, 이미지 사용 이력, 사진 승인, 글 한 편 단위 검수·업로드 확인을 유지한다.

4. **페르소나와 경력 사실 구분:** 10년 엔지니어 같은 문체 지침을 실제 작성자 경력으로 표시하지 않는다. 현장 경험이 없으면 사례를 만들지 않는다. 제조사 사례는 스마텍 자체 사례로 바꾸지 않는다.
5. **분량은 편집 기준:** `writer.md` 상단 2,000자 하한과 뒤의 1,500~2,000자 안내, `seo-guide.md`의 최적 분량 주장이 충돌한다. 현재 검사 기준은 따르되 이를 Google·네이버의 공식 순위 기준으로 설명하지 않는다. `오일프리라 마모 부품이 없다` 같은 지침 예시도 검증한 사실의 예시로 재사용하지 않는다.
