## 작업 방식

- 대표님은 Codex/Astra high로 전환했고 앞으로 여기서 대부분 작업한다. 확인되지 않은 UI 모델 상태를 변경했다고 주장하지 않는다.
- 꼼꼼한 검토·운영 문서 개선·사이트 SEO/GEO 점검·월목 전환은 승인됐다. 30~60분 단위로 검증하면서 승인 범위 안에서 이어간다.
- 루트 AGENTS 포함 보호 파일 11개, 디자인 토큰 8개, 기존 패키지 제한은 유지한다. 인수인계 문서의 전체 목록을 읽는다.
- 승인된 변경은 범위를 명시해 커밋·push 전 검토·원격 확인까지 진행한다. 다른 사람의 미커밋 수정·로컬 설정은 포함하지 않는다.
- 대표님께는 한 단계씩 설명하고 “간단히/쉽게”라는 표현을 쓰지 않는다. 질문/의견만 요청하면 코드 작업을 시작하지 않는다.
