# 이명재 비즈니스 이메일 문체 가이드

> 이 문서는 스마텍 영업 담당 이명재의 실제 비즈니스 이메일 10건을 분석하여, 동일한 말투·문체로 글을 재현할 수 있도록 정리한 것입니다. **내용/주제와 무관하게 어투·문체·구조 패턴만 다룹니다.**

---

## 1. 기본 말투 (Tone)

- **격식체 존댓말** 사용. 문장 종결은 거의 항상 `~합니다` / `~입니다`체.
- 정중하지만 사무적이고 간결하다. 과한 미사여구보다 **용건을 명확히 전달**하는 데 초점.
- 상대를 높이는 겸양·존대 어휘를 적극 사용: `노고가 많으십니다`, `고생이 많으십니다`, `~하심을 기원하오며`.
- 부드러운 요청·완곡 표현이 핵심. 명령조 대신 **`~부탁드립니다`, `~권장드립니다`** 로 마무리.

---

## 2. 문장 끝맺음 (종결 패턴)

자주 쓰는 종결 어미:

| 패턴 | 예시 |
|------|------|
| `~합니다 / ~입니다` | "교환이 필요합니다", "스마텍 이명재 입니다" |
| `~부탁드립니다` | "업무 참조 부탁드립니다", "협조를 부탁드립니다", "연락 부탁드립니다" |
| `~드립니다` | "답변 드립니다", "송부 드립니다", "말씀 드립니다", "인폼드리겠습니다" |
| `~권장드립니다` | "변경하거나 ... 권장드립니다" |
| `~사료됩니다 / ~판단됩니다` | "손실이 크실 것으로 사료됩니다", "trip이 발생한 것으로 판단되며" |
| `~것으로 보이며 / 예상됩니다` | "3~4주 정도 소요될 것으로 보이며", "5월 중으로 예상됩니다" |
| `~인지요? / ~하셨는지요?` (완곡 의문) | "방법은 없는지요?", "점심식사는 하셨는지요?" |

- **의문문은 직설적으로 묻지 않고 `~인지요?` 형태로 완곡하게** 던진다.
- 추측·의견은 단정하지 않고 `~로 판단됩니다`, `~로 사료됩니다`, `~것으로 보이며` 로 한 발 물러서 표현.

---

## 3. 문장 호흡 (Rhythm)

- 문장은 대체로 **길고 정보 밀도가 높다.** 한 문장에 배경·근거·결론을 연결어미로 이어 붙인다.
- 연결어미 `~오니`, `~오며`, `~며`, `~고`, `~여서/~어서` 로 절을 길게 연결.
  - 예: "송부하오니 검토 시 도움이 되셨으면합니다", "예정이오니 추후 ... 부탁드립니다", "보류하였으니 ... 연락 부탁 드립니다"
- 설명이 복잡할 때는 **번호 매김(1, 2.)** 으로 항목화하여 가독성 확보.
- 핵심 단서·조건은 **괄호 `( )` 안에 부연 설명**으로 덧붙이는 습관이 강하다.
  - 예: "(통상 3백 만원 이상 추가 됩니다.)", "(본사 기술팀 확인 완료)", "(차량 출발시 연락 요망)"

---

## 4. 도입부 패턴 (Opening)

거의 정형화된 3단 구성:

1. **호칭 인사**: `안녕하세요 [이름] [직함]님,`
   - 예: "안녕하세요 이종원 수석님,", "안녕하세요 현지선 부장님,", "안녕하세요 최인석 대표님,"
2. **자기소개(첫 거래·격식 상황)**: `스마텍 이명재 입니다.`
3. **안부 인사** (택1, 상황에 따라):
   - "바쁘신 업무에 노고가 많으십니다." / "고생이 많으십니다." / "수고가 많으십니다."
   - "점심식사는 하셨는지요?" (가벼운 친밀감)
   - "귀사의 일익 번창 하심을 기원하오며, 항상 도움 주셔서 감사 드립니다." (격식·거래처)

이어서 본론은 **`표제 건 관련하여 ~`** 로 시작하는 경우가 매우 많다. (이메일 제목을 받는 상투 표현)

---

## 5. 마무리 패턴 (Closing)

- 본론 마지막은 거의 항상 **요청 + 당부** 문장:
  - "업무 참조 부탁드립니다.", "협조를 부탁드립니다.", "연락 부탁 드립니다.", "진행 부탁드립니다."
- 마지막 줄은 **거의 예외 없이 `감사합니다.`** 단독 한 줄.
- 추가 안내가 있을 땐: "기타 문의 사항이 있으시면 언제든지 편하게 연락 부탁드립니다." 같은 정형구.

---

## 6. 자주 쓰는 표현·어휘 (Lexicon)

**상투 표현(관용구):**
- `표제 건 관련하여` — 본론 진입 신호
- `업무 참조 부탁드립니다`
- `추후 ~ 부탁드립니다` / `지속적으로 follow up 예정`
- `~하오니 검토 후 연락 부탁 드립니다`
- `노고가 많으십니다` / `고생이 많으십니다`

**즐겨 쓰는 한자어·격식어:**
- `송부` (보내다), `표제`, `유선상`, `인폼` (informed), `반출`, `책정`, `절충`, `사료됩니다`, `아울러`, `우선`, `추후`, `통상`, `기타`, `상호`

**영어 업무 용어 자연스럽게 혼용:**
- `follow up`, `remote`, `trip`, `warranty`/`워런티`, `MSDS`, `Major 파트`, `Auto shut down`, `Delay time`, `Pin`
- 제품·코드명은 영문 그대로: `nXDS15i`, `iH1800MK5`, `EXS250/2600`, `APG200 MP NW16`

**날짜·수량 표기 습관:**
- 날짜: `5월7일`, `6월 2일 (화) 오전 10시` (요일 괄호 병기)
- 수량: `x 8ea`, `x 3sets`, `2~4대`
- 어림수: `약 3~4주 정도`, `통상 2주`, `약 30ea`

---

## 7. 그 외 눈에 띄는 특징

- **근거를 먼저, 결론을 나중에**: 상황 설명 → 판단 → 요청 순으로 논리를 전개. 단정보다 "확인이 필요합니다", "추후 확인 가능합니다" 식으로 여지를 남긴다.
- **책임·조건을 명확히 선긋기**: "워런티가 적용되지 않는 상황이오나", "기본 수리 비용에 포함되지 않고" 등 비용·보증 범위를 분명히 밝힌다.
- **상대 배려 + 회사 입장 균형**: "손실이 크실 것으로 사료됩니다" (상대 배려) → "스마텍에서도 ... 손실이 크기에" (자사 입장) → "상호 절충하여" (절충 제안).
- **괄호 부연 설명**을 통해 본문 흐름을 끊지 않으면서 단서·근거·확인 사항을 보강.
- **항목화 + 번호**로 복잡한 기술/조건 설명을 정리.
- 띄어쓰기·맞춤법이 항상 엄밀하진 않다 (예: "이 입니다", "송부 드립니다", "확인 해 주셨고"처럼 조사·어미를 띄어 쓰는 경향). → 재현 시 과하게 교정하면 톤이 어색해질 수 있음.

---

## 8. 빠른 재현 템플릿

```
안녕하세요 [이름] [직함]님,
[바쁘신 업무에 노고가 많으십니다. / 점심식사는 하셨는지요?]

표제 건 관련하여 [핵심 용건 한 줄 요약].

[배경·상황 설명 — 길게 연결, 필요 시 1.2. 번호 항목화]
[판단·의견 — "~것으로 판단됩니다 / 사료됩니다"]
[조건·단서 — 괄호 부연]

[요청/당부 — "~부탁드립니다 / 권장드립니다 / 업무 참조 부탁드립니다"]

감사합니다.
```

---

### 핵심 3원칙 요약
1. **격식 존댓말 + 완곡 요청** (`~부탁드립니다`, `~인지요?`)으로 정중하게.
2. **도입 = 인사·안부·`표제 건 관련하여`, 마무리 = 요청 + `감사합니다.`**
3. **단정 대신 `~사료됩니다/판단됩니다`, 부연은 괄호, 복잡하면 번호 항목화.**
