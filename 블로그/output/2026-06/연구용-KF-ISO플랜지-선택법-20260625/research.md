# Research: KF vs ISO-K 플랜지 선택 기준

## 상담 배경
- 한국재료과학 박준영 박사 / nEXT400D 배관 어댑터 문의
- nEXT400D 인렛 플랜지: DN160 ISO-K
- 백킹 포트: NW25
- 기존 배관이 KF 계열이라 어댑터 필요

## KF(NW) 플랜지 — Quick Flange / Klein Flange
- 별칭: NW, QF, KF (모두 동일 규격)
- 규격: NW10, NW16, NW25, NW32, NW40, NW50
- 조립: O링 센터링 + 클램프 1개. 공구 없이 손으로 조립/분리 가능
- 진공 등급: 10⁻⁸ mbar 수준 (Viton O링 기준)
- 주 용도: RV/nXDS 백킹펌프, 소형 터보펌프 백킹라인, 로터리 펌프 연결배관
- 장점: 빠른 분리·재조립, 저비용
- 단점: NW50 이상 없음, 고진공 시스템 주 인렛 연결 불가

## ISO-K 플랜지 — ISO Clamp Flange
- 규격: DN63, DN100, DN160, DN200, DN250, DN320, DN400, DN500
- 조립: 센터링 링 + 클램프(소형) 또는 볼트(대형, ISO-F)
- 진공 등급: 10⁻⁸~10⁻¹⁰ mbar (Viton 또는 Buna-N O링 기준)
- 주 용도: 터보펌프 메인 인렛(nEXT400D=DN160 ISO-K), 챔버 포트, 확산펌프
- 장점: 대구경 가능, 고진공 신뢰성 높음, 빠른 분리(클램프 방식)
- 단점: KF 대비 부품 무거움, 클램프 조임 토크 관리 필요

## CF(ConFlat) 플랜지
- 규격: CF35, CF40, CF63, CF100, CF160, CF200
- 조립: 나이프엣지 + 알루미늄/구리 개스킷 볼트 체결 (공구 필수)
- 진공 등급: UHV 10⁻¹² mbar
- 주 용도: UHV 챔버, 표면분석장비, 이온빔
- 장점: 최고 진공도, 베이킹 가능
- 단점: 재사용 어려움(개스킷 교체), 분리·재조립 번거로움

## nEXT 시리즈 플랜지 규격
| 모델 | 인렛 | 백킹포트 |
|------|------|---------|
| nEXT55/85 | NW40, DN63 ISO-K, DN100 ISO-K | NW16 |
| nEXT240/300 | DN100 ISO-K, DN100 CF | NW25 |
| nEXT400D | DN160 ISO-K, DN160 CF | NW25 |
| nEXT730D | DN160 ISO-K, DN160 CF | NW25 |
| nEXT930D | DN200 ISO-K, DN200 CF | NW25 |
| nEXT1230H | DN200 ISO-K, DN200 CF, DN200 ISO-F | NW40 |

## 자주 나오는 어댑터 조합
- KF40 → ISO-K63: RV12 백킹 라인을 nXDS15i에 연결
- NW25 → NW40: nEXT400D 백킹포트(NW25) → GXS160 인렛(ISO100) 중간 연결 시
- ISO-K160 → ISO-K100: nEXT400D를 DN100 배관 시스템에 연결
- ISO-K63 → NW40: 소형 터보 인렛을 기존 KF 배관에 연결

## 선택 기준 요약
1. **DN63 이하**: 항상 KF(NW) — 빠른 교환, 저비용
2. **DN63~DN160**: KF 없음 → ISO-K 필수
3. **UHV(10⁻¹⁰ mbar 이하)**: CF 플랜지만 적합
4. **어댑터 필요 시**: 센터링 링 규격 반드시 확인 (KF ↔ ISO-K 직접 어댑터 존재)
