## 업체 및 공정 (H사)

- 업체 업종: 귀금속 기반 촉매 제조·재활용 전문
- 주요 분야: 자동차·화학·환경·선박용 촉매
- 연구소 운영: 촉매 성능·내구성 분석을 위한 자체 기술연구소 보유
- 진공 활용 공정: 촉매 표면 분석(XPS, BET 등), 질량분석기(MS·GC-MS) 등 정밀 분석장비

**공정 특성**
- 촉매 표면 분석에는 10⁻⁸~10⁻¹⁰ mbar 수준 초고진공 요구
- 오일 성분 유입 시 시료 오염 → 분석 데이터 신뢰도 저하
- 따라서 청정 건식 진공 시스템이 필수

## T-Station 85D (TS85D1001) 제품 사양

✅ [Edwards T-Station 85 Datasheet — edwardsvacuum.com]

| 항목 | 사양 |
|------|------|
| 모델 | T-Station 85D (TS85D1001) |
| 터보분자펌프 | nEXT85D |
| 백킹펌프 | XDD1 건식 다이어프램 펌프 |
| N₂ 펌핑속도 (NW40) | 47 L/s |
| 도달진공도 | <5×10⁻¹⁰ mbar |
| N₂ 압축비 | >1×10¹¹ |
| 백킹펌프 속도 | 1.2 m³/h (50Hz) |
| 소음 | ≤56 dB(A) |
| 중량 | 17 kg |
| 입구 플랜지 | NW40 / ISO63 / CF63 |

**분석장비 적합성 근거**
- XDD1 다이어프램 백킹펌프: 오일 완전 무사용 → 시료 오염 위험 없음
- 도달진공도 <5×10⁻¹⁰ mbar: XPS·질량분석기 요구 진공도 충족
- 일체형 컨트롤러: 단일 버튼 시작/정지, 게이지 연동 가능 → 연구실 조작 편의성
- 17 kg 경량·소형: 실험실 벤치탑 설치 가능
