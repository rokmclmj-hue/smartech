## 2. Edwards Ultragrade 오일 종류별 사양

### 2-1. Ultragrade Performance 15 (광물유)

- **점도**: 15 cSt @ 40°C ✅ [Edwards Ultragrade 15/19/20/70 MSDS, DCC1 No.705, 2012]
- **인화점**: 220°C (428°F) ✅ [Edwards Ultragrade MSDS]
- **비중**: 0.86 @ 15°C ✅ [Edwards Ultragrade MSDS]
- **품목번호**: H110-26-010 (1L), H110-26-013 (4L) ✅ [Edwards Ultragrade MSDS]
- **권장 펌프**: E2M0.7, E2M1.5 (소형 2단) ✅ [Edwards E2M 소형 카탈로그]
- **특징**: 소형 2단 로터리 펌프에서 고도달진공도(3×10⁻³ mbar)와 우수한 윤활 성능을 동시에 제공하는 용도로 설계

---

### 2-2. Ultragrade Performance 19 (광물유) — RV 계열 표준 오일

- **점도**: 55 cSt @ 40°C ✅ [Edwards Ultragrade MSDS]
- **인화점**: 220°C (428°F) ✅ [Edwards Ultragrade MSDS]
- **비중**: 0.86 @ 15°C ✅ [Edwards Ultragrade MSDS]
- **품목번호**: H110-25-010 (1L), H110-25-013 (4L), H110-25-020 (20L) ✅ [Edwards Ultragrade MSDS]
- **권장 펌프**:
  - RV3, RV5, RV8, RV12 (출하 시 기본 충전) ✅ [Edwards RV 카탈로그]
  - E1M18, E2M18, E2M28 ✅ [Edwards E2M 소형 카탈로그]
- **오일 용량**:
  - RV3/RV5: 최대 0.70L ✅ [Edwards RV 카탈로그]
  - RV8: 최대 0.75L ✅ [Edwards RV 카탈로그]
  - RV12: 최대 1.00L ✅ [Edwards RV 카탈로그]
  - E1M18/E2M18: 0.75~1.05L / E2M28: 1.2~1.5L ✅ [Edwards E2M 소형 카탈로그]
- **특징**: 고도달진공도(총압 기준 2.0×10⁻³ mbar)와 우수한 증기 처리 성능. 첨가제 패키지로 산화 저항성·증기압 안정성이 탁월한 광물유

---

### 2-3. Ultragrade Performance 20 (광물유)

- **점도**: 103 cSt @ 40°C ✅ [Edwards Ultragrade MSDS]
- **인화점**: 220°C (428°F) ✅ [Edwards Ultragrade MSDS]
- **비중**: 0.86 @ 15°C ✅ [Edwards Ultragrade MSDS]
- **품목번호**: H110-24-010 (1L), H110-24-013 (4L) ✅ [Edwards Ultragrade MSDS]
- **권장 펌프**: 확인 불가 (카탈로그에서 명시 모델 미발견 — 문의 필요)
- **특징**: Ultragrade 19보다 점도가 약 2배 높은 광물유. 고온·고부하 환경에서 오일 막 두께를 더 두껍게 유지해야 하는 용도에 적합할 것으로 추정되나, 특정 모델 권장 여부는 확인 불가

---

### 2-4. Ultragrade Performance 70 (광물유) — E2M 중대형 및 nES 표준 오일

- **점도**: 70 cSt @ 40°C ✅ [Edwards Ultragrade MSDS]
- **인화점**: 230°C (446°F) — Ultragrade 15/19/20 대비 10°C 높음 ✅ [Edwards Ultragrade MSDS]
- **비중**: 0.86 @ 15°C ✅ [Edwards Ultragrade MSDS]
- **품목번호**: H110-28-010 (1L), H110-28-011, H110-28-013 ✅ [Edwards Ultragrade MSDS]
- **권장 펌프**:
  - E2M40, E2M80, E2M175, E2M275 (HC·AZ·EX 계열 공통) ✅ [Edwards E2M 중대형 카탈로그]
  - nES40~nES750 (Performance 70 또는 Endurance Extend 110 중 선택) ✅ [Edwards nES 카탈로그]
- **오일 용량**:
  - E2M40: 2.2~4L / E2M80: 4~6.3L / E2M175: 16~25L / E2M275: 18~28L ✅ [Edwards E2M 중대형 카탈로그]
  - nES40: 1L / nES65: 2L / nES100: 2L / nES200: 5~9L / nES300: 8.5~11.5L / nES470~750: 20~23L ✅ [Edwards nES 카탈로그]
- **특징**: 고온 산화 안정성이 Ultragrade 19보다 우수. E2M/nES 중대형 오일식 펌프의 표준 광물유

---

### 2-5. Ultragrade Endurance Extend 110 (합성유) — nES 연장 교환 주기용

- **점도**: 확인 불가 (카탈로그에 수치 미기재)
- **권장 펌프**: nES 시리즈 전 모델 ✅ [Edwards nES 카탈로그]
- **특징**: Performance 70 대비 교환 주기를 연장해주는 합성유 계열. "use of the Ultragrade Endurance Extend 110 oil provides extended service intervals"로 명시 ✅ [Edwards nES 카탈로그]
- **선택 기준**: 연속 가동(24시간 운전)이나 빈번한 서비스가 어려운 환경에서 Performance 70 대신 선택. 구체적인 연장 주기 수치는 확인 불가.

---

### 2-6. PFPE / Fomblin (불소계 합성유) — 산소·반응성 가스 환경 전용

- **제품명**: Fomblin® YVAC 06/6 ✅ [Edwards 공식 웹샵 uk.my.edwardsvacuum.com]
- **품목번호**: H11301019 (1kg/532ml), H11301020 (5kg/2660ml) ✅ [Edwards RV 카탈로그 주문정보]
- **적용 펌프**:
  - RV 계열 PFPE 사전처리 모델 (A65X09XXX 계열) ✅ [Edwards RV 카탈로그 주문정보]
  - E2M FX 계열 (산소 농도 >21% 환경 대응 모델) ✅ [Edwards E2M 중대형 카탈로그]
  - E2M18 PFPE, E2M28 PFPE ✅ [Edwards E2M 소형 카탈로그]
- **도달진공도(PFPE 사용 시)**:
  - RV 계열: 2.0×10⁻² mbar (Ultragrade 19 사용 시 2.0×10⁻³ mbar의 약 10배 낮음) ✅ [Edwards RV 카탈로그]
  - E2M18 PFPE: 3×10⁻¹ mbar / E2M1.5 PFPE: 1×10⁻² mbar ✅ [Edwards E2M 소형 카탈로그]
- **특징**: "부식 저항성과 화학적 불활성을 가진 PFPE. 일반 석유계 오일이 신속히 파괴되는 악조건 공정용" ✅ [Edwards 공식 유지보수 지식베이스]
- **중요 주의사항**: PFPE 펌프에는 반드시 Fomblin 오일만 사용해야 하며, Ultragrade 광물유와 혼용 절대 불가. PFPE 준비 펌프는 별도 주문(A65X09XXX 계열), Fomblin 오일은 별도 구매.

## 3. 오일 교환 주기

### 3-1. 공식 수치 현황

Edwards 공식 카탈로그·웹페이지에서는 모델별 구체적인 교환 시간(시간 단위)을 웹에 공개하지 않는다. 교환 주기는 각 펌프의 Instruction Manual에 명시되어 있으며, 공식 문서에서 확인된 원칙은 아래와 같다.

- **일반 원칙**: "vacuum pump oil should be changed every three to six months, or more frequently for high-use applications" ✅ [Edwards 공식 vacuum-pump-oil 페이지]
- **nES 연장 주기**: Ultragrade Performance 70 대신 Ultragrade Endurance Extend 110 사용 시 교환 간격 연장 가능 ✅ [Edwards nES 카탈로그]
- **예방정비 원칙**: "펌프 운전 시간을 기준으로 한 사전예방적 서비스 일정 수립이 중요" ✅ [Edwards 공식 유지보수 지식베이스]

### 3-2. 교환 주기 판단 기준 — 교환해야 할 징후 (오일 상태 이상 신호)

Edwards 공식 지식베이스에서 명시한 교환 필요 징후 ✅ [Edwards 공식 유지보수 지식베이스]:

| 징후 | 설명 |
|------|------|
| 오일 색상 변화 (어두워짐) | 허용 불가능한 수준의 열화·오염·응결을 의미 |
| 오일 레벨 감소 | 사이트 글라스(sight glass)로 확인, 즉시 보충 필요 |
| 과도한 진동 | 오일 열화 또는 내부 마모 신호 |
| 비정상적으로 높은 오일 소비 | 오일 씰 또는 배기필터 점검 필요 |
| 높은 운전 온도 | 오일 열화 가속화 신호 |
| 도달진공도 저하 또는 배기속도 감소 | 오일 오염 또는 열화의 직접적 결과 |

### 3-3. 실험실 환경 교환 주기 가이드라인

공식 수치 기준으로 정리한 가이드라인 (개별 모델 매뉴얼 확인 필수):

| 사용 환경 | 권장 교환 주기 |
|-----------|---------------|
| 경부하 (간헐적 사용, 청정 가스) | 6개월마다 ✅ [Edwards 공식 페이지] |
| 중부하 (일상적 실험실 사용) | 3개월마다 ✅ [Edwards 공식 페이지] |
| 고부하 (연속 가동, 응축성 가스) | 3개월 미만 — 수시 육안 점검 병행 ✅ [Edwards 공식 페이지] |

## 4. 오일 선택 기준 — 공정 가스 종류에 따른 분류

| 공정 환경 | 권장 오일 | 근거 |

| 일반 청정 가스 (N₂, Ar, He 등) | Ultragrade 19 (RV/E2M 소형) 또는 Ultragrade 70 (E2M 중대형·nES) | ✅ [Edwards 각 모델 카탈로그] |

### 오일 혼용 절대 금지

- 광물유(Ultragrade 15/19/20/70)와 PFPE(Fomblin)는 혼용 불가
- PFPE 준비 펌프에 광물유 사용 금지, 그 반대도 금지
- 오일 교환 시 기존 오일을 완전히 배출 후 신유 충전 필수
