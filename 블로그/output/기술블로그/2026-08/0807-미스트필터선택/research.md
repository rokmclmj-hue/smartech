## 1. 오일로터리펌프 배기 구조와 미스트 발생 원리

- 오일 로터리 베인(로터리 베인) 펌프는 회전 로터가 오일로 밀봉된 상태로 기체를 압축·배출하는 구조다. 배기 과정에서 오일이 미세한 안개(미스트) 형태로 함께 배출구를 통해 빠져나간다. ✅ [스마텍 내부 자료 — product_master_table.csv, 미스트필터(EMF) 항목 비고란: "오일 로터리 펌프 배기 필터"]
- Edwards 미스트필터(EMF/MF 시리즈)의 명시된 용도는 "오일 실드 펌프(oil sealed pump) 배출구에서 나오는 공정 가스 중 오일 미스트(증기)를 제거하고, 냄새와 오일 증기가 대기·작업 환경으로 유입되는 것을 방지"하는 것이다. ✅ [Edwards 공식 — us.my.edwardsvacuum.com / uk.my.edwardsvacuum.com 카탈로그 페이지, MF100 제품 설명]

## 2. 미스트필터 미사용 시 문제 — 눈에 보이는 것 / 안 보이는 것

### 눈에 보이는 문제
- 미스트필터 없이 배기하면 배출구 주변 장비 표면·바닥에 오일 얼룩이 남는다. 배기구에서 나온 오일 미스트가 응축되어 주변 구조물에 부착되기 때문이다. ✅ [Edwards 공식 카탈로그 — MF/EMF 필터 제품 설명(오일 미스트 제거 목적 명시)에서 원리 확인]
- 상담기록에서도 실제 현장에서 EMF 필터를 배기구에 장착해 사용하는 사례가 확인된다. 한미정밀화학(가공업체, 이니셜 처리) 담당자는 RV8 펌프용 재고 문의 중 "필터도 같이 있나요?"라고 물었고, 스마텍 담당자가 "이 급에 맞는 게 EMF10번"이라고 안내했다. 고객은 필터 형태를 "약간 회색 계열, 에드워드 거는 사각형"이라고 직접 묘사했다 — 현장에서 필터 유무·형태를 명확히 인지하고 재구매하는 소모품이라는 뜻이다. ✅ [스마텍 내부 자료 — 상담기록, 2026-06-17 통화]

### 안 보이는 문제 (작업자 노출)
- 미스트필터 없이 배기된 오일 증기는 작업장 공기 중으로 퍼지며, 작업자가 이를 흡입하는 오일 흄(fume) 노출 문제로 이어진다. 이는 EMF/MF 필터가 "냄새와 오일 증기가 대기 및 작업 환경(workplace)에 도달하지 않도록 제거한다"고 명시한 목적과 정확히 반대되는 상황이다. ✅ [Edwards 공식 카탈로그 — MF100 제품 설명 "prevent it from reaching the atmosphere and the workplace"]
- 밀폐되거나 환기가 부족한 실내 설치 환경일수록 이 문제가 누적되기 쉽다. 다만 정량적인 노출 기준치(작업환경 허용 농도 등)는 이번 리서치의 허용 소스(Edwards/스마텍 내부자료)에서 확인되지 않아 본문에는 수치로 단정하지 않는다. ⚠️ [확인 불가 — 작업환경 노출 기준 수치]

## 3. 펌프 용량별 미스트필터 라인업

스마텍 내부 제품 마스터 테이블(product_master_table.csv, 19.미스트필터(EMF).pdf 기준)에 등록된 3개 모델은 아래와 같다. ✅ [스마�텍 내부 자료 — product_master_table.csv id 85~87]

- **EMF3**: 유량 3 m³/h / NW10 플랜지 / 적용 펌프: E2M0.7, E2M1.5 / 섬유 복합 미스트 필터 + 활성탄 탈취 필터 + 압력 릴리프 밸브 내장
- **EMF10**: 유량 12 m³/h / NW25 플랜지 / 적용 펌프: RV3, RV5, RV8 등 / 섬유 복합 미스트 필터 + 활성탄 탈취 필터 + 오일 레벨 확인창
- **EMF20**: 유량 20 m³/h / NW25 플랜지 / 적용 펌프: RV12, E1M18, E2M18 / 섬유 복합 미스트 필터 + 활성탄 탈취 필터 + 오일 드레인 키트 옵션

### MF100 (중형 펌프용) — 스펙 확인 결과

- **적용 펌프**: E2M40 ~ E2M80 (E2M28 포함 라인업). ✅ [Edwards 공식 카탈로그 — uk.my.edwardsvacuum.com "Oil mist filter (clean) - application oil return kit (E2M40 to E2M80)" / us.my.edwardsvacuum.com "MF100 Outlet Mist Filter" 제품 페이지]
- **유량(m³/h) 및 정확한 플랜지 규격(NW 사이즈)**: Edwards 공식 페이지(my.edwardsvacuum.com 계열)가 로그인 필요 페이지라 상세 스펙 표를 직접 열람하지 못했다. 화이트리스트에 없는 재판매업체 사이트(idealvac.com, ajvs.com 등)에서 NW25 플랜지·12kg 등 수치가 검색됐으나 **허용 소스가 아니므로 인용하지 않는다.** 🚫 [idealvac.com, ajvs.com — 수치 미사용, 화이트리스트 외 소스]
- **결론**: 글에는 "펌프 용량에 맞는 대용량 미스트필터(MF100)"로만 서술하고, 유량·플랜지 수치는 기재하지 않는다.

### MF300 (대형 펌프용) — 스펙 확인 결과

- **적용 펌프**: E2M175 ~ E2M275 (E1M175, E1M275 포함 라인업). ✅ [Edwards 공식 카탈로그 — emea.my.edwardsvacuum.com "Outlet mist filter (clean) - oil return kit (E2M175 to E2M275), A50005000" 제품 페이지]
- **유량(m³/h) 및 정확한 플랜지 규격(NW 사이즈)**: MF100과 동일하게 공식 상세 페이지 열람이 막혀 있고, 확인된 수치는 비허용 소스(idealvac.com 등)뿐이다. **인용하지 않는다.** 🚫 [idealvac.com — 수치 미사용]
- **결론**: 글에는 "펌프 용량에 맞는 대형 미스트필터(MF300)"로만 서술하고, 유량·플랜지 수치는 기재하지 않는다.

### 공통 구조 (일반적 서술 수준)

- EMF3 기준으로 확인된 구조는 "섬유 복합 미스트 필터 + 활성탄 탈취 필터, 압력 릴리프 밸브 내장"이다. ✅ [product_master_table.csv id 85]
- MF100/MF300도 오일 미스트 제거·탈취 기능을 갖는 동일 계열 제품이나, 내부 구조가 EMF3와 완전히 동일하다고 단정할 근거는 확인하지 못했다. 글에서는 "일반적으로 유사한 구조로 만들어진다" 수준의 완곡한 표현만 사용한다. ⚠️ [MF100/MF300 상세 내부 구조 — 확인 불가, 완곡 표현으로 서술]
