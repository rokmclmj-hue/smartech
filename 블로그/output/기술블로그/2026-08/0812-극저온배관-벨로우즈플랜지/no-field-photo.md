# 현장사진 미사용 사유

`data/현장사진/` 전체 폴더(01~07)를 "배관", "벨로우즈", "플랜지", "극저온" 키워드로 확인했다.

- `03_현장설치/식품제약_발효조배관_20260710.jpg`가 유일하게 "배관" 관련 후보였으나, 실제 내용은 식품·제약 발효조의 재킷 배관(가열/냉각용 보온재 배관)이며 진공 이중배관·벨로우즈·플랜지와는 무관한 장비다. 사진에 찍힌 배관이 본문에서 설명하는 진공 배관 부품과 다른 것을 붙이면 "펌프 종류 불일치" 사고(2026-07-13 재발 방지 원칙)와 같은 성격의 문제가 되므로 사용하지 않았다.
- `진공펌프 현장연결 배관사진.jpeg` / `_preview_진공펌프 현장연결 배관사진.jpg`는 이미 `used-images.json`에 `0718-수냉공랭-드라이펌프` 글에서 사용 완료되어 재사용 대상에서 제외했다.
- 극저온·벨로우즈·플랜지를 직접 촬영한 현장사진은 확인 결과 없음.

**대체 조치**: image-maker.md 2순위 규칙에 따라 `public/images/products/hardware.png`(플랜지·O링·클램프·벨로우즈 등 실제 부품을 촬영한 홈페이지 제품 이미지)를 사진1.png로 사용했다. 캡션에는 "참고 이미지"임을 명시해 실제 현장 촬영 사진과 구분했다. 나머지 이미지는 AI 생성 다이어그램으로 구성했다.
